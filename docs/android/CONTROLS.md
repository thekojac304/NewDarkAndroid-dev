# Touchscreen controls

The same guide is in the app: launcher → **Controls guide**. Controls were tested on a Galaxy S26 Ultra.

| Control | What it does |
| --- | --- |
| Left half of the screen | Floating stick: drag anywhere to walk |
| Right half | Swipe to look |
| **FIRE** | Shoots while held; drag while holding to aim |
| **USE** | Opens doors, picks things up |
| **JUMP**, **CROUCH**, **RELOAD** | Do what they say (CROUCH uses the installation's own crouch key) |
| `<` `>` | Tap: previous/next weapon. Hold: weapon wheel |
| **AMMO** | Tap: cycle ammo. Hold: ammo and firing-mode wheel (psi powers when the psi amp is equipped) |
| **ITEM** | Hold: hypos and patches wheel |
| **II** | Tap: menu, or skip a cutscene. Hold: quick save, quick load, logs |
| **MODE** | Switches LOOK / CURSOR (inventory, PDA, keypads, menus) |
| **KBD** | On-screen keyboard (save names, console) |
| **SET** | Touch settings: layout editor, button size and opacity, look speed, haptics, cursor style, wheel contents |

## Radial menus

Hold a wheel button (400 ms). The wheel opens **around your finger, on the button you are holding**. Without lifting,
slide onto an entry and release to choose it. Release on the button itself, or slide well outside the wheel, to cancel.
At a screen edge the entries fan out toward the middle so none is cut off.

## Cursor styles (SET, then MORE)

- **Direct** (default): tap where you want to click; drag to drag.
- **Relative**: drag like a trackpad; tap to click; hold still to pick up and drag. Speed is adjustable.

Settings are saved in the app's `touch-settings.cfg` and survive updates. A USB or Bluetooth keyboard and mouse also
work. Gamepads are not supported.
