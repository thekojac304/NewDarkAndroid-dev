## 8. Signing recommendations

See [SIGNING.md](SIGNING.md). Summary: no key exists anywhere; source release needs none. If a distributable build is
ever authorized, generate a dedicated release key offline, keep it and its passwords outside the repo, load them from
the environment into a `release` signing config, publish the certificate SHA-256, and mind that changing from the debug
key forces an uninstall (saves lost) unless saves are copied out first. Packaging review: application ID
`local.newdarkandroid.ss2`; `minSdk 26`, `targetSdk 34` (a Play Store listing would need 35+; irrelevant to a sideloaded
or source release); only permission `VIBRATE`; `allowBackup=false`; arm64-only; native libraries uncompressed and 16 KB
aligned; debug build type only (no release build type yet).
